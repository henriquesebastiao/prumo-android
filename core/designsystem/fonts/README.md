# Fontes

As fontes da interface vão empacotadas no APK, em `src/main/res/font/` (docs/decisoes.md, D06). Ambas são os arquivos variáveis oficiais do repositório [`google/fonts`](https://github.com/google/fonts), sob a SIL Open Font License 1.1 (textos ao lado):

| Arquivo | Fonte | Origem | Licença |
|---|---|---|---|
| `google_sans_flex.ttf` | Google Sans Flex (eixos `ROND`, `opsz`, `slnt`, `wdth`, `wght`) | `ofl/googlesansflex/GoogleSansFlex[ROND,opsz,slnt,wdth,wght].ttf` | `OFL-GoogleSansFlex.txt` |
| `jetbrains_mono.ttf` | JetBrains Mono (eixo `wght`) | `ofl/jetbrainsmono/JetBrainsMono[wght].ttf` | `OFL-JetBrainsMono.txt` |
